# Resenha 2.2.1 — entrar pelo código de novo

## Correção
- Entrar numa sala pelo código voltou a funcionar. Os servidores públicos que o Resenha usava para achar a sala pararam de responder ("Não consegui consultar a descoberta"). Agora o Resenha usa um serviço próprio para isso, e os servidores públicos ficam só de reserva.
- Se a conexão com a descoberta demorar, o Resenha espera mais antes de desistir.
- Vale também para o Resenha no navegador do celular (PWA).

Atualize todo mundo da sala: quem ficar na 2.2.0 continua sem conseguir entrar pelo código.
