# Resenha 2.3.1 — tela inicial unificada e app mais leve

## Tela inicial
- A tela inicial do app agora tem o mesmo layout do Hub do launcher: uma coluna só, com perfil e senha recolhidos até você precisar deles.

## Desempenho
- Com a janela escondida, as animações decorativas pausam e o app gasta menos.
- O contorno de quem está falando atualiza com menos frequência, e o microfone mutado nem é medido. O corte de voz continua igual de rápido.

## Visual
- Pequenos ajustes de brilho e contraste em alguns temas.
