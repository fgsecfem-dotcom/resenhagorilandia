# Resenha 2.0.1 — live mais leve

## Codificar uma vez só
- Antes, quem transmitia codificava a tela uma vez para cada amigo que assistia. Agora o primeiro amigo que assiste pelo app recebe direto e repassa para os outros com a 2.0.1: quem joga e transmite codifica uma vez só.
- Se esse amigo sair da live, quem transmite avisa os outros e eles passam a receber de outro jeito sozinhos, sem a tela ficar preta.
- Amigos ainda na 2.0.0 e quem assiste pelo navegador continuam recebendo direto.

## Placa de vídeo
- A live prefere H.264, que o Windows e o Mac codificam na placa de vídeo (NVIDIA, AMD ou Intel). Antes ia em VP8, quase sempre pelo processador.

## Ver o que está acontecendo
- Em "Alterar transmissão" aparece quantos estão assistindo, quantas vezes o PC está codificando, se é pela placa de vídeo ou pelo processador, o fps e se a live está limitada pelo processador ou pela internet.
