# Resenha 1.4.0-preview.4 — Pipoca

Esta versão troca a identidade visual pela Pipoca. Inclui as funcionalidades da prévia 3.

- Rosto da Pipoca com balde de pipoca no ícone do executável, janela, bandeja e favicon.
- Pipoca comendo pipoca no canto superior esquerdo e na marca da barra lateral.
- Fundos removidos das imagens JPG fornecidas com a ferramenta imagegen, mantendo a referência visual. A extração por IA pode apresentar pequenas diferenças em relação aos originais.
- Ícone Windows com tamanhos de 16 a 256 pixels; imagens PNG com transparência real, compatíveis com os temas claros e escuros.

## Abrir

Extraia TODO o ZIP para uma pasta. Encerre o Resenha antigo pelo menu da bandeja (Sair) e abra Resenha.exe na pasta nova. Não execute de dentro do ZIP e não copie apenas o EXE. O nome do aplicativo e o perfil de dados permanecem Resenha.

Se um atalho fixado ainda mostrar o ícone antigo, remova esse atalho e fixe o executável novo. O Windows pode manter ícones em cache.

Abrir-Compativel.cmd continua disponível como opção para quem precisa do modo de compatibilidade.

Esta é uma entrega local; não foi publicada no GitHub. Para orientações e limitações das funcionalidades da prévia anterior, consulte CHANGES-preview-3.md no código-fonte.
